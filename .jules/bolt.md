## 2024-05-17 - React memoization of complex geometry functions
**Learning:** `MapCanvas` and `WorldMap` previously performed O(N) array passes (like `projector` to find bounds and `mapEdges` to deduplicate and link graph edges) on every render, ignoring standard React performance practices. When adding `React.memo` to child components, it is critical to also stabilize their event handler props (like `onLocationClick`) using `useCallback` in the parent, or the memoization check will always fail due to inline functions re-instantiating.
**Action:** Always check parent-supplied prop stability (especially inline arrow functions) when optimizing child components with `useMemo` or `React.memo`. If parent props cannot be easily stabilized, rely on internal `useMemo` for heavy lifting rather than a blanket `React.memo` that will trivially fail.
