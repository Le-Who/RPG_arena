## 2024-05-18 - [Missing Access Control Middleware on Export]
**Vulnerability:** The API route for updating narrative settings (`src/app/api/settings/narrative/route.ts`) was missing the `withIdentityWork` access control middleware wrapper at the export level (`export const POST = handlePOST;`), while using `withCurrentIdentityWork` inside the handler. This allowed unauthenticated processing of the request payload via `readJsonObject`, bypassing CSRF checks and request diagnostics.
**Learning:** Next.js API route handlers must be wrapped with appropriate access control middleware (e.g., `withIdentityWork`, `withAdminAccess`) at the export level. This ensures request validation, CSRF checks, and telemetry execute *before* any request payloads are parsed, preventing unauthenticated payload processing or DoS risks.
**Prevention:** Ensure that all exported handler constants (`export const POST = ...`) are wrapped with the relevant access control middleware, rather than placing the checks inside the function logic after parsing inputs.
