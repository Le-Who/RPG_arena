# Сверка описаний и индикации Chronicle Engine

Дата сверки: 19 октября 2026. Текущая продуктовая версия — **2.10**. Это актуализация сведений о существующем коде, без объявления нового функционального релиза.

## Область проверки

Проверены текущие обозначения версии и дат в `src/`, `public/`, `scripts/`, `tests/`, manifest/lockfile, `.env.example` и README. Поиск пользовательских текстов охватывал 46 TSX-файлов; для длинных JSX-строк дополнительно извлечены отдельные литералы через TypeScript AST. Тексты сопоставлены с обработчиками и моделями данных: готовность рассказчика и памяти, доступ к кампаниям и диагностике, аккаунты, профили правил, экспорт, автозаполнение, обновление вкладки и работа без сети. Действующие руководства сверены с package scripts, test preloader, CI, Dockerfile и ledger `0000`–`0019`.

Датированные планы, исследовательские материалы, отчёты проверок и исходники в `revisions/` рассматриваются как история. Упоминания 2.7/2.8/2.9, прежних Node/Next и старых количеств тестов в историческом контексте сохраняются. Старые имена `v22-*` обозначают проверки контрактов, введённых в 2.2, и не означают текущую версию приложения.

## Защита от повторного рассогласования

`src/lib/product-info.json` задаёт продуктовую версию, дату сверки и краткое описание; `product-info.ts` форматирует дату для интерфейса. UUID сборки в `/api/version`, идентификаторы service worker, версии переносимого JSON и исторические номера миграций имеют собственные контракты.

`npm run check:docs` дополнительно проверяет заголовок и первую дату состояния в тексте текущего README. Регрессии запускают настоящий checker на временном проекте: неверные сведения дают две ошибки, правильные проходят, исторический раздел 2.7 остаётся допустимым. Правильная дата внутри fenced-примера не маскирует устаревшую текущую дату.

## Проверки

Выполняются в текущем рабочем дереве на Node 22.23.3 из ранее подготовленного локального runtime. Обычный test preloader использует dummy PostgreSQL URL и очищает credentials. Браузерные проверки используют loopback-серверы и синтетические API; рабочая БД и живые провайдеры не используются.

- `tests/docs-check.test.ts`: новые регрессии сначала воспроизвели пропуск ошибок версии/даты и подмену текущей даты примером; итоговые **11/11** вошли в focused-прогон **133/133**. Повторён интеграционный контракт канонического базового пресета; старое утверждение о точном тексте «Автономный режим» обновлено вместе с продуктовой формулировкой.
- `scripts/system-copy-browser.ts`: настоящий `SystemPanel`, шесть desktop/mobile сценариев; отсутствие подключения, внешний рассказчик без Gemini, отключённые функции, heartbeat, keyboard process и retry/Escape, отсутствие overflow и page errors. Исходный компонент воспроизвёл устаревшую подпись worker до исправления.
- `scripts/game-copy-browser.ts`: PASS на desktop 1440×1000 и mobile 390×844. Проверка библиотеки воспроизвела «Доступно офлайн» до исправления; затем прошли библиотека, создание пресета, игра, память, галерея, справка и сведения о версии. Мобильное пояснение о сервере проверяется на видимость в форме, поскольку боковая иллюстрация на телефоне скрыта. Финальные снимки просмотрены.
- `npm run typecheck`, `npm run lint`, штатная production-сборка Next 16.4.2 (Turbopack): exit 0. Сборка использовала dummy URL, пустые переменные из локальных `.env*` и выключенные startup-миграции; пользовательские credentials не передавались.
- Production HTTP на отдельном loopback-порту: PASS для версии/даты/ограничения аккаунтов в `/blueprint`, общего описания HTML/manifest и совпадения `/api/version` с `.next/BUILD_ID`. Запросов к кампаниям, БД и провайдерам в этом smoke нет.
- `npm run check:docs`: PASS, **97 файлов / 396 локальных ссылок**; ссылки и heading anchors корневого `AGENTS.md` проверены отдельно. `next dev` нормализовал только уровень заголовка своего generated-блока согласно установленному `generate-agent-files.js`; блок сохранён.
- `git diff --check`: PASS. Структурное сравнение lockfile с HEAD подтвердило неизменность dependency graph; поменялись только корневые имена пакета.
- Независимое read-only review выявило оставшиеся офлайн-подписи и две инструкции. После исправлений повторное review не нашло actionable замечаний в изменённых частях.
- Полный `npm test`: **1220/1220**, fail/cancelled/skipped/todo **0**, exit 0 на Node 22.23.3; продолжительность около 14 минут. После последней правки только синтетического NPC повторно прошли затронутые `tests/ui-mock.test.ts` (**3/3**) и браузерный сценарий; прикладной код после production-сборки не менялся.

Изолированный UI fixture не проверяет авторизацию Next, SQL-конкуренцию или реальное качество AI. Наличие исправлений не утверждает, что они опубликованы на внешнем сервере.
