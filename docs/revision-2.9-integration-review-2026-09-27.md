# Сравнение и интеграция ревизии 2.9

Источник: `revisions/2.9-revision`. База сравнения: `2ff44cb`. Дата: 27 сентября 2026. Исходная папка сохранена без изменений. После нормализации CRLF/LF содержательные отличия ограничены 25 файлами; массовые отличия остальных файлов были переводами строк.

| Предложение | Решение | Обоснование и изменения |
|---|---|---|
| Распорядок и ожидаемое присутствие NPC | Принято с исправлениями | Закрывает полезную часть ранее отложенного WORLD-2b. Обязательна цитата окончательного рассказа, отсутствующая цитата/рассказ закрывает запись. Отклоняются намерения, неоднозначные места, прошедшие разовые окна и пересечения; две смены в одном месте сохраняются отдельно. NPC без записи в кампании не возникает из расписания. Память использует общий актуальный факт распорядка NPC вместо оставшихся старых фактов разных мест. |
| История связей и знания | Принято как ограниченный срез | Использует принятые события и цитаты, хранит ход. Не объявлено полноценным графом знаний, полным журналом или защитой от раскрытия секретов. |
| Неявка и автоматический штраф −5 | Исходный алгоритм отклонён, полезная часть сохранена | Две границы хода не доказывают отсутствие между ними; `missEffect` назначался моделью без проверки обещанного условия. Сохранены переносы/история и уведомление о просрочке. Часы не меняют статус встречи/отношения; совместимость исторических полей оставлена. |
| Снятие состояний | Переработано | Исходник принимал любое долгое действие за отдых, `remove` предмета за лечение и упоминание врача за помощь. Теперь нужны соответствующее действие и завершённое событие героя; только `consume`, проверка подходящего средства, неудачного медицинского броска, субъекта еды/отдыха и получателя лечения. Сон сам по себе не лечит. Каталог «ё» и границы слов исправлены. Семантические ограничения эвристик явно документированы. |
| Финал и продолжение арки | Принято и дополнено | Полные поля новой арки проверяются сервером и UI. Изменение транзакционно, сохраняет архив, переключает `mainQuest` и роль `isMain`, не дублируется при повторе. Старые цели и эпилоги сохраняются; экспорт показывает архивные эпилоги после продолжения. |
| HTML-книга и manifest | Принято с уточнением границ | Экранирование, единый Markdown-источник, CSP также в самом файле, `private, no-store`. Manifest не назван гарантированной установкой/PWA; офлайн работает книга. |
| Последствия, первый ход, мемоизация ленты | Принято | Группы показывают принятые данные, примеры зависят от story shape, ввод не требует повторной сборки ленты. Причины NPC остаются заметками, а цифры финала — статистикой кампании. Производительность и доступность требуют отдельных измерений. |
| Перенос PGlite в production dependencies | Не принят | Библиотеки используются тестами; runtime-потребности в поставке нет, lockfile не обновлён. |
| Изменения инструкции PostgreSQL/PGDG | Не перенесены | Существующий путь PGlite/pgvector Docker достаточен для этой интеграции. Исторические миграции, journal и readiness сохранены. |
| Новый roadmap | Переработан | Сохраняются прежние ID и незакрытые критерии; нет преждевременного объявления штрафов, полного NARR-3 или PWA готовыми. Добавлен прямо запрошенный приоритет JEV-3 с измеримыми срезами и контролем стоимости/неопределённости. |

Проверка шести первичных регрессий на исходном коде поставки дала шесть падений; после исправлений они проходят. Дополнительное независимое ревью выявило смешение героя и получателя лечения и перезапись двух смен одного места; для обоих случаев добавлены воспроизводящие тесты и исправления. PGlite-проверка использует реальные обработчики PATCH/export, ownership, транзакцию, историю целей и portable-экспорт. Итоговая проверка:

- `npm test`: 455/455, без пропусков. После финальной правки пояснений каталога отдельно повторены 14 тестов состояний и безопасности — все прошли.
- `npm run typecheck`, `npm run lint`, `npm run build`, `npm run check:docs` и `git diff --check` прошли. Проверка документации: 48 файлов, 127 локальных ссылок. Сборка использовала синтетический `DATABASE_URL` и `CHRONICLE_AUTO_MIGRATE=0`.
- Playwright на изолированном production-сервере с API-фикстурами: проверены обязательные четыре поля новой арки, расписание/знания/история NPC, раскрытие блока с клавиатуры. На ширине 390 px ширина документа также 390 px. Снимки: `output/playwright/revision-29-desktop.png`, `output/playwright/revision-29-mobile.png` (локальные игнорируемые артефакты).
- Ограничения браузерной проверки: серверные prefetch-запросы соседних страниц вернули 500 из-за намеренно недоступной синтетической БД; они не покрыты API-фикстурами. Это проверка выбранных состояний UI, не полный end-to-end, аудит доступности или проверка живых моделей. Пользовательская БД и платные провайдеры не использовались.

## AGENTS.md

По доступной истории `git log --follow -- AGENTS.md` первый вариант в `c3f96fd` содержал только автоматически генерируемое предупреждение Next.js. В `a49b80f` добавлено правило pgvector. Признаков удаления прежнего содержательного руководства в этой истории нет. В рамках интеграции добавлены правила поиска актуальной реализации, продуктовые инварианты, правила AI/канона/изоляции/миграций, проверок и обновления документации; генерируемый блок сохранён.

Контракты и ограничения: [описание 2.9](world-social-and-consequences.md). Приоритеты: [стратегическое дополнение](development-roadmap-2026-09-27.md), [основной реестр](superpowers/plans/roadmap.md).

Руководство AGENTS.md сверено с официальными [рекомендациями для GPT-6 Astra](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra) и [правилами AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md): контекстные ссылки, проектные инварианты, пропорциональные проверки, без обязательного перечитывания всех документов перед каждой правкой.

После обсуждения риска устаревания из AGENTS.md убраны перечень внутренних модулей и копии команд запуска. Актуальные команды берутся из `package.json`, структура определяется поиском реализации, вызывающего кода и тестов. При расхождении документации и кода требуется выяснить намеренное поведение по тестам и истории; ни один источник не объявлен безусловно правильным.
