# Выборочная интеграция поставок 2.10

**Цель:** сопоставить обе поставки с текущим кодом, перенести полезное с исправлением обнаруженных ошибок и сохранить исходники в `revisions/`.

**Архитектура:** существующие серверные правила и атомарная запись остаются основой. Независимые изменения проверяются отдельно; общие типы, переносимый JSON, миграции и финальный конвейер хода согласуются при интеграции. Реальная БД и платные провайдеры не используются.

**Основание:** поручение владельца от 29 сентября и `AGENTS.md`. Стек: Next.js 16, React 19, TypeScript, Drizzle/PostgreSQL, PGlite, npm.

## Решения и последовательность

- [x] Сравнить содержимое после нормализации CRLF/LF: обе поставки содержат независимые дополнения к одной текущей базе.
- [x] Последствия: перенести ресурсы и цели до/после, сверить с окончательным состоянием после repair, проверить legacy и строгий JSON.
- [x] Очередь: адаптировать ротацию владельцев с атомарным выбором; сохранить lease и повторное получение identity, добавить аддитивную миграцию 0017 и PGlite-проверки.
- [x] Договорённости: перенести правки владельца, устойчивую версию, provenance и атомарную память; проверить ownership, lease, stale, rollback. Автоматическое наблюдение по одному имени и пересечению интервала не принимать как доказательство участия.
- [x] Измерения: ограниченная включаемая оператором телеметрия, административный отчёт, бюджет промпта и Server-Timing; миграция 0018, строгий JSON, тесты границ и приватности.

- [x] Не переносить автоматическое доверие X-Forwarded-Host: действующий CHRONICLE_PUBLIC_ORIGIN уже задаёт явную доверенную границу развёртывания.

## Проверки

Тестовый preload `tests/helpers/test-environment.ts` исключает реальные ключи и БД. Поведенческие тесты новых функций сначала запускаются до переноса; обнаруженные дефекты получают отдельные регрессии. Браузерный сервер запускается с фиктивным loopback DATABASE_URL и без реальных credentials, API заменены `scripts/ui-mock.ts`. Миграции проверяются на disposable PGlite. Наличие mock-проверок не устанавливает качество AI, нагрузочную готовность или поддержку установки на всех устройствах.
