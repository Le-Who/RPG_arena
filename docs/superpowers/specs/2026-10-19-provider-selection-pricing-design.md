# Выбор ИИ по задачам, цены и возможности моделей

Статус: **согласованный дизайн**, 19 октября 2026. Пользователь одобрил реализацию и поставку с дополнительным требованием убрать пояснения под кнопки справки. Исходная версия приложения — `b2ae462`. Актуальное поведение описано в [контракте сервисов](../../text-providers-operations.md).

## Задача пользователя

Независимо выбирать сервис для текста и картинок: например, Gemini/OpenRouter для рассказчика и Pollinations/OpenRouter для иллюстраций. Сократить число подключений и решений, показать стоимость до использования и исключить модели, которым обязательно требуется исходное изображение, из создания картинки с нуля.

Критерий: две понятные задачи, несколько совместимых вариантов и цена с единицей. Полный каталог, технические ID и тарифные детали раскрываются по необходимости. Дешевизна не объявляется доказательством качества.

## Текущее состояние

- Рассказчик: Gemini, OpenRouter, Pollinations; картинки: только Pollinations, независимо от рассказчика.
- Один личный Pollinations key уже используется для текста и личных картинок. Зашифрованный личный OpenRouter key есть, но адаптера изображений нет.
- У иллюстрации сохраняются провайдер, источник оплаты, модель и владелец; повтор не выбирает нового плательщика.
- Каталоги выбрасывают цены при преобразовании для интерфейса. Нынешняя проверка `text` на входе недостаточна для определения генерации без исходника.

Код: [Pollinations catalog](../../../src/lib/pollinations-model-catalog.ts), [text catalog](../../../src/lib/text-model-catalog.ts), [visual adapters](../../../src/lib/visual-provider.ts), [visual settings](../../../src/lib/visual-settings.ts).

## Рекомендуемый интерфейс

Экран **«ИИ для ваших историй»** содержит две независимые карточки:

1. **Рассказчик:** сервис, модель/профиль, стоимость с доступным объяснением, действие «Изменить».
2. **Иллюстрации:** «Выключены» либо сервис, модель, плательщик, цена за картинку или оценка при выбранных параметрах, действие «Изменить».

Редактируется одна задача за раз. До подтверждения верхняя карточка помечает новый выбор «Не применено»; неподключённый сервис всегда помечен «Нужно подключить». Отмена возвращает применённое значение. Применение настройки без ключа не означает готовность генерации. Изменение картинок не меняет рассказчика и его Live-переключатель. Подключение само по себе не запускает генерацию. При первом использовании иллюстрации необязательны; существующий явный выбор сохраняется.

Подробности сравнения цен, требований к исходникам и устройства подключения открываются доступными кнопками «?» в диалогах; стоимость, плательщик, ошибки и несохранённые изменения остаются видимыми.

Общий раздел **«Подключённые сервисы»**: Gemini, OpenRouter, Pollinations. Ключ вводится один раз. Выбор уже подключённого сервиса не вызывает повторную форму ключа. Общий ключ OpenRouter для текста и изображений обозначается явно; его удаление объясняет влияние на обе задачи.

Не показывать недоступную оплату аккаунтом приложения как основной вариант подключения. Прежний сохранённый, но недоступный вариант объясняется; личная оплата не включается молча.

Jev, embeddings, технические лимиты, ручное назначение Gemini-моделей и несколько ключей остаются в дополнительных настройках. Смена рассказчика не обещает подключить векторную память автоматически.

## Короткий список

Основной выбор — до 3–5 актуально доступных моделей. Нужны подтверждённая совместимость с задачей и серверными ограничениями. Для рассказчика одного текстового выхода недостаточно: важны структурированный ответ и существующие parser/guard/reducer. Метка JSON не доказывает качество игрового хода. «Проверено для историй» допустимо только после сценарного тестирования.

Под списком — **«Все модели и поиск»**: имя/издатель, фильтры, сортировка, тарифные детали. Официальные модели первыми; community/private доступны в полном каталоге с обозначением и соблюдением разрешений ключа. Текущая выбранная модель закрепляется в коротком списке в пределах его общего лимита. Сохранённая модель остаётся видимой даже при исчезновении из каталога; замена всегда явная.

Не использовать без оценки качества категории «максимальное качество» и «лучший баланс». Первые честные группы: **«Фиксированная цена»**, **«Зависит от параметров»**, **«Нет данных о цене»**. «Недорогие» означает сравнение на одной основе.

## Источники цен

Проверены публичные API и официальные документы 19 октября 2026. Генерации и платные вызовы не выполнялись.

**Pollinations:** `/text/models` и `/image/models` содержат ставки, `pricing_units`, `flat_rate`, варианты и сборы. Примеры текущего API:

| Модель | Честное отображение |
|---|---|
| DreamShaper 8 LCM | 0,0001 Pollen / изображение |
| Z-Image Turbo | 0,004 Pollen / изображение |
| Qwen Image 2.1 | 0,02 Pollen / мегапиксель для генерации |
| Nano Banana 2 Lite | оценка 0,0336 Pollen за выходное изображение 1K, плюс текстовые расходы |

Последняя оценка основана на 1120 выходных токенах изображения; это не универсальная константа. У некоторых моделей есть отдельный сбор за запрос. Основная валюта — Pollen; FAQ указывает приблизительно $1 ≈ 1 Pollen. `paid_only=false` не означает бесплатно, а бюджет OAuth-ключа не является подаренным балансом.

Источники: [image API](https://gen.pollinations.ai/image/models), [text API](https://gen.pollinations.ai/text/models), [схема цен](https://github.com/pollinations/pollinations/blob/main/shared/registry/model-info.ts), [реестр изображений](https://github.com/pollinations/pollinations/blob/main/shared/registry/image.ts), [FAQ](https://github.com/pollinations/pollinations/blob/main/enter.pollinations.ai/POLLEN_FAQ.md).

**OpenRouter:** для текста `/api/v1/models`; для картинок `/api/v1/images/models` и записи конкретного endpoint `/api/v1/images/models/{id}/endpoints`. Pricing содержит billable, unit, cost_usd и условия. Seedream 4.5 / `seed`: $0,04 за изображение; FLUX.2 Pro: $0,03 за мегапиксель. Ставки image-токенов нельзя выдавать за фиксированную цену картинки. Общий `/models` описывает верхний endpoint, а не гарантирует цену любого маршрута. Если карточка показывает конкретную endpoint-цену, запрос должен придерживаться этого endpoint либо явно объявленного диапазона.

Источники: [Image API](https://openrouter.ai/docs/guides/overview/multimodal/image-generation), [Seedream](https://openrouter.ai/api/v1/images/models/bytedance-seed/seedream-4.5/endpoints), [FLUX](https://openrouter.ai/api/v1/images/models/black-forest-labs/flux.2-pro/endpoints), [routing](https://openrouter.ai/docs/guides/routing/provider-selection).

**Gemini напрямую:** Model resource содержит возможности/лимиты, но не тариф. Нужна датированная таблица по официальной странице цен, включая окончание вводных ставок. Тариф одноимённой модели у посредника может отличаться. Наличие ключа не доказывает бесплатную квоту Google-проекта; показываем стандартный платный тариф и условие бесплатного.

Источники: [Model resource](https://ai.google.dev/api/models), [официальные цены](https://ai.google.dev/gemini-api/docs/pricing).

## Сопоставление и обновление цен

- Фиксированные полные цены изображений сравниваются за один результат. Оценки — при одинаковых реально поддерживаемых размере/качестве и со всеми известными сборами.
- Если размер или число image-токенов не установлены, показывается исходная ставка. Частичная стоимость выхода помечается отдельно от полного запроса.
- Неизвестная цена — «Нет данных», не ноль. Она идёт после сопоставимых цен.
- Для текста на главном экране — цена явно обозначенного примера одного запроса; в подробностях — ставки входа/выхода/кэша. В макете пример: 8000 входных + 1000 выходных токенов, без кэша, инструментов и дополнительных вызовов.
- Пример запроса не равен цене игрового хода: resolution, narration, review/repair, память и компакция могут создавать несколько запросов.
- У каждой цены: источник, checkedAt, условия, fixed/estimate/unknown. Stale помечается. Старая ставка не становится гарантией списания; изменение цены не меняет модель автоматически.
- Информация о цене сама по себе не создаёт гарантированный денежный лимит. Нельзя обещать такой лимит без подтверждённого механизма провайдера.

## Генерация, редактирование и референсы

У Pollinations `prunaai/p-image-edit` имеет `text,image` на входе и проходит нынешний фильтр, но обработчик требует минимум один исходник. У OpenRouter окончательная проверка по endpoint: положительный `input_references.min` исключает его из создания с нуля. Пример — Recraft V4 Styles. SVG-only endpoints не подходят текущей растровой галерее.

У Pollinations не найден общий достоверный публичный `requires_image` для всех моделей. Нужна небольшая версионируемая таблица подтверждённых capabilities/exclusions по canonical ID и aliases, с источником и датой. Известные edit-only исключаются. Неизвестные не попадают в короткий список как подтверждённая генерация.

Модели, умеющие и генерировать, и редактировать, остаются доступными, если исходник необязателен. Слово edit в названии и наличие image среди входов не являются универсальным запретом.

Проверка действует в каталоге и на сервере при создании/запуске. Ручной ID не обходит известную несовместимость. Ошибка каталога не приводит к подмене сохранённой модели.

Источники: [Pruna handler](https://github.com/pollinations/pollinations/blob/main/gen.pollinations.ai/src/image/models/prunaModel.ts), [Pruna tests](https://github.com/pollinations/pollinations/blob/main/gen.pollinations.ai/test/image/prunaModel.test.ts), [Recraft endpoint](https://openrouter.ai/api/v1/images/models/recraft/recraft-v4-styles/endpoints).

## Границы будущей реализации

Нормализованный каталог сохраняет задачу, provider/canonical ID/endpoint, capabilities с уровнем подтверждения, billing lines/variants/fees и checkedAt/stale. Авторизация и кэш остаются owner/key-scoped; текущие разрешения проверяются отдельно от срока кэша.

Каталоги загружаются при раскрытии выбора и не блокируют bootstrap или обычное сохранение. Pollinations отдаёт цены списком. У OpenRouter детали endpoint загружаются для выбранной модели/короткого списка с ограниченной параллельностью; десятки запросов при открытии страницы недопустимы.

Для изображений OpenRouter нужны отдельный POST JSON `/images`, bounded JSON/base64 decode, растровый MIME/bytes, прежние таймауты/лимиты/lease/quota. Произвольный URL из ответа не скачивается. Сохранение credentials отделено от настройки рассказчика. OpenRouter для изображений в первом срезе — личный аккаунт; общего ключа приложения не добавляем.

Независимые visualProvider и image models потребуют append-only миграции после `0020`. Endpoint/размер/качество, если выбраны, сохраняются у иллюстрации для повторов. Старые Pollinations-записи сохраняют прежнюю семантику. Чужой владелец, новый ключ или ошибка не меняют плательщика автоматически.

## Приёмка будущей реализации

1. Матрица провайдеров текста × изображений, независимые настройки, один credential на сервис, удаление общего ключа с понятным эффектом.
2. Реальная edit-only модель с text+image, optional-reference и SVG-only cases; запрет обхода ручным ID.
3. Per-image/MP/token, варианты/сборы, нулевая и неизвестная цена, stale и вводные тарифы.
4. Поздний каталог не стирает новую правку; повторы сохраняют provider/payer/model/endpoint/options.
5. Отзыв сессии/ключа, смена владельца, rotation, migration fresh/replay, старые записи.
6. Desktop 1280, mobile 390/320, клавиатура/фокус, короткий список и видимая цена выбранной модели.
7. После разрешения на реализацию — измерения первой загрузки/сохранения с настоящей БД. Платная генерация требует отдельного явно разрешённого прогона.

## Альтернативы

**Рекомендуется:** две задачи + общие подключения + короткий список. **Готовые сочетания сервисов** пригодны как необязательный стартовый помощник, но количество сочетаний растёт; независимые настройки всё равно нужны. **Автовыбор самого дешёвого** не предлагается как основной режим: стоимость не доказывает качество, меняется и зависит от параметров.

Этот проект решения не утверждает качество перечисленных моделей, успешную генерацию через OpenRouter или наличие описанного интерфейса на рабочем сайте.

Примеры подключений условные; сетевых запросов генерации нет. Проверка документации и локальных ссылок выполнена; продуктовые исходники, production и БД не изменены.
