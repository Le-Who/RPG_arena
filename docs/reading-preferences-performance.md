# Первая отрисовка настроек чтения (v2.7)

Раньше корневой интерфейс начинал с темы `midnight`. Клиент применял сохранённую тему лишь после `/api/auth/me`, параллельных `/api/sessions`, `/api/settings`, `/api/workspace` и повторной проверки `/api/auth/me`. Поэтому пользователь с `sepia` или `contrast` видел смену палитры после загрузки пространства. Эта последовательность объясняет задержку темы; фактические 3 секунды и доли БД/сети пока не измерены.

Теперь при изменении настроек чтения браузер сохраняет четыре косметических значения (`theme`, `textScale`, `measure`, `motion`) в `localStorage` под версионированным ключом. Маленький синхронный скрипт в `<head>` корневого layout проверяет все значения по разрешённым спискам и ставит CSS-атрибуты до разбора `<body>` и загрузки данных пространства. После ответа `/api/workspace` клиент обновляет кэш и атрибуты из серверной записи; при смене профиля сбрасывает их до значений по умолчанию, пока не получит настройки нового профиля. При ошибке сохранения возвращает прежние значения.

Серверная запись остаётся источником истины и синхронизации между устройствами. Локальный кэш может временно устареть после изменения настроек на другом устройстве или внешней смены авторизации; это влияет только на вид страницы до ответа API. При ошибке загрузки пространства сохранённая палитра остаётся до успешного ответа. Кэш не содержит идентификатор профиля, ключи, кампании, права доступа или настройки AI. Ошибка или запрет `localStorage` не ломает загрузку: используется исходная тема, затем серверный ответ.

Перенос всего пространства в cookie не ускорит запросы кампаний и добавит передачу данных при каждом HTTP-запросе. Чтение cookie в root layout потребовало бы серверной работы перед ответом и усложнило бы кэширование; для косметических значений здесь достаточно браузерного кэша. Приватные данные и проверку владельца нельзя брать из cookie или `localStorage` без серверной проверки.

Только после измерения сокращать последовательность запросов или объединять ответы, сохраняя защиту при смене профиля между запросами.
