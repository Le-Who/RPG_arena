# Провайдеры рассказчика

Состояние реализации: 27 сентября 2026. [README](../README.md) · [Roadmap](superpowers/plans/roadmap.md).

## Настройка

В «Настройки → Рассказчик» выберите Gemini напрямую, OpenRouter или Pollinations. Для внешнего провайдера сохраните собственный API-ключ и ID текстовой модели. Каталог загружается из публичного API; ID также можно ввести вручную. Доступность каталога не гарантирует доступ к модели по вашему тарифу и поддержку требуемой JSON-схемы. При отказе модели приложение показывает ошибку, не ослабляет проверку состояния.

Выбор принадлежит профилю владельца и применяется к его кампаниям. Это пока не индивидуальное назначение модели каждой кампании. Ключи OpenRouter/Pollinations рассказчика отделены от ключа OpenRouter для Jev и серверного ключа Pollinations для иллюстраций. Приложение не подставляет ключ одного назначения вместо другого.

Через выбранного провайдера выполняются narration/resolution, review/repair, автозаполнение новой истории, компакция и семантическое извлечение. Для внешнего провайдера используется одна явно выбранная модель; Gemini сохраняет прежние профили роутинга, а его автозаполнение — Flash Lite. Настройки моделей Gemini относятся к прямому Gemini, не к ID внешних каталогов.

Эмбеддинги по-прежнему использует `gemini-embedding-2` с отдельными прямыми Gemini-ключами. Без них внешний рассказчик работает, семантические текстовые задачи доступны, но векторная индексация/поиск не становятся автоматически доступны. Сохранённые факты и исходная история сохраняются.

## Pollinations: подключение кошелька

Можно сохранить личный secret key вручную либо нажать «Подключить кошелёк Pollinations». Для второго пути оператор регистрирует App Key и точный callback URI в Pollinations, затем задаёт серверу:

```dotenv
POLLINATIONS_APP_KEY=pk_your_registered_app
POLLINATIONS_REDIRECT_URI=https://your-domain.example/api/settings/pollinations/callback
```

Локальная разработка допускает HTTP localhost/127.0.0.1; для обычного домена требуется HTTPS. URI должен точно совпадать с регистрацией. Отсутствие этих переменных отключает OAuth-кнопку, но не ручное сохранение ключа.

Используется authorization code + PKCE S256. Краткоживущая HttpOnly-cookie зашифрована и привязана к владельцу, state и конфигурации. Обмен кода и хранение полученного `sk_` выполняются сервером. Callback прикрепляет ключ и срок действия, не переключает провайдера и не включает платные вызовы автоматически. Затем пользователь выбирает модель, включает рассказчика и сохраняет настройки.

Запрашиваются scope `usage`, начальный бюджет 5 Pollen и срок 7 дней; пользователь принимает условия на стороне Pollinations. Это параметры consent, не гарантия стоимости конкретной модели. Просроченный токен требует повторного подключения. Удаление ключа из Chronicle прекращает его использование приложением; для отзыва выданного доступа на стороне провайдера используйте кабинет Pollinations. Подключение не включает опциональную наценку разработчика.

Контракт сверялся с [официальным Connect User Wallets](https://github.com/pollinations/pollinations/blob/main/BRING_YOUR_OWN_POLLEN.md). Реальный consent требует зарегистрированного приложения и действия пользователя; mock-тесты его не заменяют.

## Хранение, расходы и ошибки

Перед запуском применить `npm run migrate`: миграция `0016_text_provider_settings.sql` добавляет настройки с Gemini по умолчанию, зашифрованные ключи и срок Pollinations. Настроить общий web/worker keyring по [руководству](secret-storage-operations.md). Исторические миграции не изменяются. Rotation и перенос старого профиля учитывают новые секреты; API отдаёт только признаки наличия ключей.

Попытки внешних провайдеров учитываются раздельно как `openrouter:<model>` и `pollinations:<model>`. Локальный дневной предел каждой внешней модели использует существующее поле Flash; число Gemini-ключей его не умножает. Это предел HTTP-попыток, не денежный лимит. У провайдера остаются собственные баланс, тарифы и ограничения. Повтор временной ошибки — максимум один, та же модель, новая резервация квоты.

Внешний рассказчик не переключается на Gemini или другую модель приложения. При ошибке, исчерпании локального лимита или истёкшем подключении включённого внешнего рассказчика ход не сохраняется, включая preset. Явное выключение Live сохраняет возможность процедурного preset. Внутреннюю маршрутизацию шлюза Pollinations нельзя приравнять к гарантии конкретного upstream; у OpenRouter приложение запрещает provider fallback.

Структурированный JSON и стрим проходят существующие parser/guard/reducer/lease/atomic commit. Указание JSON schema провайдеру само по себе не означает принятие результата сервером. Пакеты SSE, оборванный поток, ошибка провайдера, отмена и лимит ответа проверяются транспортом. Ключи и сырые ответы ошибок не включаются в диагностику.

## API

- `GET/POST /api/settings/text-provider`: чтение безопасного представления и изменение настройки текущего владельца.
- `GET/POST /api/settings`: общая настройка также возвращает `textProvider`, `textModel`, `canUseLive` и, при наличии, `textKeyExpiresAt`. Интерфейс использует серверную готовность выбранного рассказчика; наличие Gemini-ключей не требуется для внешнего провайдера.
- `GET /api/settings/text-provider/models?provider=openrouter|pollinations`: публичный текстовый каталог с кратким кэшем; неизвестная поддержка schema не выдаётся за подтверждённую.
- `GET /api/settings/pollinations/connect`: доступность OAuth-конфигурации.
- `POST /api/settings/pollinations/connect`: начало consent, возвращает URL.
- `GET /api/settings/pollinations/callback`: owner/state-bound обмен одноразового кода.

## Проверка и границы

Общий transport deadline Gemini распространяется также на чтение JSON/SSE и callbacks; read/cancel, игнорирующий AbortSignal, не удерживает application promise бесконечно. Explicit usage `0` сохраняется, unknown usage не выдаётся за достоверный ноль. Ошибки и terminal telemetry используют безопасные коды. Нулевые персональные Flash/Lite/embedding limits сохраняются через settings API и прекращают новые вызовы до fetch; это допустимый запрет расхода, а не автоматический minimum 1. [Текущие регрессии и ограничения](test-coverage-audit-2026-10-09.md).

Контрактные тесты используют синтетические ответы, integration — одноразовую PGlite. После отдельного разрешения владельца 27 сентября выполнены три живых синтетических генерации через `gemini-3.5-flash-lite` и один запрос `gemini-embedding-2`. Все три ответа разобраны по схеме; потоковая сборка совпала с итоговым текстом; эмбеддинг содержит 768 конечных чисел. БД и реальные кампании не использовались. Повторяемый сценарий: [eval-gemini-provider-smoke.ts](../scripts/eval-gemini-provider-smoke.ts), запуск `node --env-file=.env.eval --import tsx scripts/eval-gemini-provider-smoke.ts --live`. Без `--live` запросы не выполняются.

Это проверка транспорта, а не оценка качества полного игрового хода: используются короткие синтетические инструкции вместо полного контекста кампании. В сцене неудачного открытия сундука модель сохранила закрытое состояние, но дополнительно предложила `danger=2`; в сцене кристаллов добавила объект. Успешный разбор JSON не доказывает обоснованность таких предложений. Их допустимость определяют серверные проверки полного хода; для вывода о качестве нужна отдельная оценка принятых изменений и финального повествования по [исследовательскому плану](superpowers/plans/2026-09-27-grounded-narrative-evaluation.md).

OpenRouter и Pollinations проверены на синтетических контрактных и интеграционных ответах, без живой генерации; OAuth consent — без настоящего кошелька. Качество конкретной модели и фактическая поддержка схемы остаются предметом отдельных контролируемых запусков. Этот документ не заявляет успешный production deploy.

Итоговая локальная проверка: полный `npm test` — 525/525; после дополнений отдельно проверены 30 тестов интеграции ходов и 3 теста готовности интерфейса. `npm run typecheck`, `npm run lint`, `npm run build` и `npm run check:docs` прошли. Браузерные проверки с подменой API покрыли desktop/mobile, клавиатуру, сохранение настроек, ошибки каталога, внешнего рассказчика без Gemini и истёкший Pollinations. Реальные публичные каталоги вернули 458 текстовых моделей OpenRouter и 187 Pollinations на момент проверки; это не статический список поддерживаемых моделей. Миграция в пользовательской БД не выполнялась.
