## Проверки существующих правильных контрактов

- **Режимы:** actual `performTurn` для preset/free × трёх profiles × typed/suggested action; preset сохраняет один ход без provider, free требует AI без canonical writes. Literal d20/2d6/null oracle, число обращений RNG и completed replay защищают единственную admitted check. Всего13 registrations; это credential-free admission, не качество live narrator.
- **Память:** worker принимает только evidence из окончательного narrator; malformed envelope не пишет, malformed отдельные facts фильтруются, корректный сосед сохраняется; player intention не является доказательством. Lease expiry запрещает запись; SQL completion trigger доказывает совместный rollback nodes/outbox. Native compaction наблюдает3 разных blocked PG PIDs, затем5 exact excerpts,5 outbox rows,0 stale UPDATEs и1 cursor UPDATE; trigger failure откатывает весь batch.
- **Очередь:** реальные независимые Node workers обслуживают фиксированный eligible backlog владельцев A/B в порядке A→B→A→B. Quotas/logs/vectors остаются у своих владельцев. Actual admin retry A меняет только A failed2; B/ready/completed/pending и canon не меняются, повтор queued0.
- **Telemetry:** отдельные module instances с независимыми native pools соблюдают persisted cap570+20+10=600 за минуту. Busy lock и SQL constraint failure освобождают client/recording и откатывают retention; тот же recorder после отказа успешно пишет. Это module instances в одном процессе, не deployment load study.
- **Восстановление:** actual `performTurn` в дочерних процессах; kill во время provider work, BUSY до controlled DB expiry, fresh process завершает original request/dice. Реальный `pg_terminate_backend` в completion trigger откатывает все state/turn/scene/memory/outbox writes; процесс сохраняется, новый backend работает. Третий процесс делает exact replay без нового provider/commit. Service boundary не создаёт route owner_activity и не меняет документированное operator cleanup orphan rows; DB expiry ускорен явно, не выдан за прошедшие90s; provider billing exactly-once не обещается.
- **Reindex authorization:** дополнительный event-gated logout после настоящего campaign lookup и до fresh config lookup возвращает401 без изменения canon/jobs и provider/after effects. Existing handler правильный; код приложения не менялся.
- **Browser retry:** Chromium отправляет actual HTTP-only identity cookies в disposable bridge с настоящими import/act/request/snapshot handlers и PostgreSQL. Потерянный committed import201 повторяется с прежним документом/ID и одним ledger. Потерянный act stream восстанавливается после reload через настоящий request ledger без второго act. Equal/older transport отдельно проверяет реальные PlayRoom/hook на сохранение проверенного state.
- **PWA:** две actual Next production-сборки A/B, один origin, две старые вкладки, установленный worker. Pending и scoped draft/item binding сохраняются при controllerchange без navigation. Pending блокирует update; добровольный reload касается одной вкладки. Build-specific old chunk доступен offline; реальные API/HTML/RSC после `context.setOffline` отказывают. Offline navigation показывает public fallback, online Retry возвращает buildB. CacheStorage содержит только разрешённые static/public shells; mobile390×844 и page errors[] проверены. Campaign API/pending status здесь synthetic; actual ledger относится к отдельному browser bridge.
